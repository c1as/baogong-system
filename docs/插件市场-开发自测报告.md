> **T08 发现并修复的真实缺陷**：纯 PHP `ZipReader` 的 3 处二进制偏移错误——
> ① central directory 头 `unpack` 起点错位 2 字节（central dir 比 local 头多 `version-made-by` 字段）；
> ② CRC-32 应为 4 字节 `V` 而非 2 字节 `v`（local + central 两处）；
> ③ EOCD 中把"central dir 大小"(+12) 误读成"central dir 偏移"(+16)。
> 修复后真实 zip 包解析/校验/解压全部通过。这直接保障了 U2 风险（内嵌 PHP 无 zip 扩展时）的纯 PHP 回退路径可用。

## 6. 合规核对

- **data/ 零覆盖**：市场仅写 `data/market-plugins/` 与 `data/plugin-market.json`；`data/plugins.json` 全程只读；App 热更只写 `public/`——三者对齐，零改 APK。
- **不排除 plugins/**：6 个必备插件仍在 `public/plugins/` 随 web 包覆盖（U1 用户拍板）；CI 打包源只读必备区，市场副本写 data/。
- **公共口径未变**：id 正则、tag `plugin-<id>-vX.Y.Z`、schema `baogong-plugin-index/1`、5MB/20MB/100 文件/深度 3、能力白名单、bg_json/bg_fail、plugin.json 契约全部保持。
- **安全**：HTTPS 强制、令牌不写日志、zip-slip/扩展名/限额/路径越界全校验、卸载只删 data 副本。
