# 报工管理系统 · 版本更新日志

> 历史版本归档：`报工系统-历史版本/baogong-vX.Y-YYYYMMDD.zip`（不含运行时 `data/`）

## v2.6 · 2026-11-22

主题：小米 MiMo 引擎、识别日志、识别与匹配增强。

### 新增

- **小米 MiMo 引擎**：新增 `mimo-v26-flash` 插件，调用小米 MiMo 开放平台 `mimo-v2.6-flash`（可切 `mimo-v2.6-pro`），支持思考模式、最大输出 Token、45 秒超时、0~2 次退避重试（限流 / 5xx / 断连）、零件库注入条数与可编辑识别指令；已纳入融合引擎默认引擎列表。
- **识别日志**：新增 `ocr-log` 插件（默认启用，能力 `report.ocr.log`），记录每次识别的引擎、耗时、字段、明细、告警与零件匹配候选，按天写入 `data/ocr-logs/YYYY-MM-DD.jsonl`；设置页可配记录级别（详细 / 精简）、保留天数（默认 14）与是否记录匹配结果，按钮为「查看日志」。
- 设置页「测试识别」按钮仅对识别引擎显示，日志插件不再显示。

### 变更

- **零件库下发**：调度层由最多 300 条提升到 8000 条，各引擎按自己的 `catalogLimit` 裁剪提示词；融合引擎可用全量零件库做图号校正。
- **融合增强**：以各路子引擎原文为依据校正图号，只采纳原文确有佐证的库内图号（容忍 1~2 位前缀差异与手写多 / 少字），防止模型按零件库「猜」出单据上没有的图号。
- **零件匹配**：模糊匹配改以整段编辑距离为主，减少「4 位数字恰好出现在别的图号里」造成的误配；弱证据（<0.72 或与次优差 <0.04）不再自动填充，留给人工选择；同分时优先与原文更接近的图号。
- **工序匹配**：支持工序尾部编号（`铣1`、`车加工（3）`）区分同一工序的多个工步。

## v2.5 · 2026-11-21

主题：移除库存数量。

### 变更

- **零件表单**：删除「库存数量」输入项，新增 / 编辑零件时不再提交该字段。
- **零件列表**：删除卡片右侧的库存快捷输入，列表更紧凑。
- **CSV 导入导出**：去掉 `库存数量` 列，模板由 32 列变为 31 列（图号、名称、材料、备注 + 9 道工序 × 3）；导入旧模板时多余的 `库存数量` 列会被忽略。
- 空状态引导文案去掉「库存」字样。

### 兼容性

- `parts.stock` 列保留，旧数据不迁移；保存、导入未带 `stock` 时沿用原值，不会把已有库存清零。`part.stock` 接口保留。
- 静态资源缓存号更新为 `?v=2.5`。

## v2.4 · 2026-11-21

主题：数据清除（带二次验证）。

### 新增

- **数据清除**：数据备份弹窗底部新增红色「数据清除」区块。清空 `parts` / `orders` / `reports` / `report_items` 四张表，并删除 `data/images/{parts,attachments,drawings}` 下的全部图片。
  - **二次验证**：配置了 `APP_PASSWORD` 时须重新输入登录密码（错误返回 403，不清除任何数据）；未配置密码时须输入确认语句「清除全部数据」（错误返回 400，不清除任何数据）。
  - **自动兜底**：执行前若存在数据，自动创建 `pre-clear` 快照，误清除可从「已有快照」恢复；快照本身不会被清除。
  - 后端新增 `data.clear` 接口与 `bg_data_clear()`。

### 修复

- 弹窗（`.modal`）增加 `max-height: calc(100vh - 40px)` 与滚动，避免快照较多时弹窗超出屏幕、底部按钮够不到。
- 静态资源缓存号更新为 `?v=2.4`，避免浏览器继续使用旧 `app.js`。

## v2.3 · 2026-11-21

主题：零件图纸、工序说明、识别图片入附件。

### 新增

- **零件多图纸**：`parts` 表新增 `drawings` 列（JSON 数组，旧库启动时自动 `ALTER`，不迁移数据）；新增 `data/images/drawings/` 目录，支持图片（JPG/PNG/WebP）与 PDF 多张上传。
  - 零件卡片显示「图纸 (N)」按钮，弹窗查看：图片在弹窗内预览，PDF 在新标签页用浏览器内置查看器打开。
  - 编辑页可上传 / 移除图纸，零件改名时图纸文件名同步重命名，删除零件时一并清理图纸文件。
  - 后端新增 `part.drawing.remove` 接口与 `bg_drawing_save / bg_drawings_rename`，`/img/` 图片接口按扩展名返回正确 MIME（含 `application/pdf`）。
- **工序说明**：工序新增 `desc` 字段；零件列表以小字号展示说明摘要，编辑表单每道工序为「名称 / 说明 / 单价」三项，CSV 导入导出扩展为最多 9 道工序（含 `工序说明N` 列）。
- **报工表单工序说明**：选零件后，每行明细下方出现可展开的「该零件工序说明」折叠条，点击查看全部有说明的工序。
- **识别图片入附件**：拍照识别报工单时，识别用的原图自动存入该报工单的图片附件并随单保存，避免识别后原图丢失（受 6 张附件上限约束）。

### 变更

- 零件列表封面图放大至 78px（手机端 62px），点击弹出大图预览；「图纸 (N)」按钮移到报工 / 编辑 / 删除三个按钮下方。
- `零件导入模板.csv` 更新为 32 列（5 基础列 + 9 道工序 × 3 列），带 BOM 便于 Excel 打开中文不乱码。

### 兼容性

- 旧数据库首次访问自动补 `drawings` 列，旧零件 `drawings` 为空数组，完全兼容。
- 部署：连同整个 `data/` 目录上传 `public/` 即可；`data/images/drawings/` 首次启动自动创建（需 Web 用户写权限）。

## v2.2 · 2026-11-21

主题：接口服务端分页，解决全量数据 300ms 瓶颈。

- 首屏改为 `bootstrap` 接口只取元信息（约 160B）；列表、统计、CSV 全部由后端 SQL 分页与合计，前端移除本地聚合。
- 新增 `parts.list/search/get/match`、`orders.list/search/get`、`reports.list/get`、`stats.list/overview`、`export.parts`、`export.stats` 等接口；表单零件 / 订单下拉改为远程搜索，详情按 id 查询。
- 补充 `reports(date)`、`report_items(report_id/order_id/part_id)`、`orders(date)` 等索引。
- 前端不再调用 `state` 接口（接口保留兼容）。
