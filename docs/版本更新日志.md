## v3.6 · 2026-11-26

主题：安全加固 + 数据层事务化重构，并同步上架腾讯云识别插件。

### 变更

- **会话与登录安全**：会话令牌改为带签名与有效期的 claims（`bg_session_ttl` / `bg_token_claims` / `bg_verify_token`），Cookie 统一由 `bg_session_cookie()` 下发，HTTPS 下自动带 `Secure`；未设置 `APP_PASSWORD` 时服务端拒绝非本机登录（403 并提示配置），`bootstrap` 的计数改为 SQL `COUNT(*)`，避免未认证请求触发全量读库与逐条计算。
- **接口地址安全**：新增 `bg_url_https_public()` / `bg_ip_public()`，只允许公网 HTTPS 域名，拒绝 `http`、IP 直连、回环与内网域名；统一 HTTP 客户端 `bg_http()`（超时、重定向与证书处理），插件市场下载增加最大字节数与超时限制。
- **数据层重构**：新增 `public/lib/repo.php`，把零件/订单/报工写操作收敛为事务化仓储函数（`bg_part_insert/update/delete`、`bg_order_*`、`bg_report_*`、`bg_report_items_replace`、`bg_seq_next_no`、`bg_auto_order_for_item`），唯一约束冲突统一走 `bg_unique_error()`；新增 `public/lib/query.php` 负责列表筛选与统计的 SQL 构建，替换内存聚合。接口路径与返回结构不变。
- **其他加固**：备份与临时目录清理收敛到 `bg_clear_dir_files()`；图片、CSV 校验补充边界处理。
- **插件安全与上架**：`baidu-ocr` 升级 1.3.2、`qwen35-ocr` 1.0.2、`mimo-v26-flash` 1.0.2，接口地址只允许官方域名（检查页与调用侧双重校验）；`handwriting-lexicon` 的 AI 组织器同样要求公网 HTTPS；新增 `tencent-vision` 1.0.0 上架插件市场（腾讯云 OCR + 混元 Hy4 双引擎，支持 fuse / parallel / primary 三种收口）。
- **前端**：`store`/`backup`/零件与报工表单的兼容性修复；静态资源版本统一为 `?v=3.6`。

### 验证

- 全部改动 PHP 文件 `php -l` 通过（34 个），改动 JS 通过 `node --check`。
- 本机冒烟：登录成功；`parts.list`、`orders.list`、`reports.list`、`stats.list`、`stats.overview`、`data.stats`、`backup.list`、`plugins.list`、`plugin.market.list`、`net.check` 均 200；零件新增 → 修改 → 删除全链路通过，测试数据已清理。

## v3.3 · 2026-11-24

主题：修复插件市场安装/升级失败。

### 修复

- **安装失败「解压后的插件清单不合法」**：`BG_PM_Installer::landPackage()` 把插件包解压到 `.tmp-<id>-<版本>-<随机>` 目录后，用 `bg_plugin_manifest()` 做二次校验，而该校验要求「目录名 == 插件 id」，临时目录名永远不满足，导致所有市场插件安装/升级必然失败。改为先建 `.tmp-*/<id>/` 子目录再解压，校验通过后把该子目录原子改名到 `data/market-plugins/<id>`。
- 安装成功的响应里插件 `source` 补为 `market`（此前回落成 `builtin`）。
- 新增遗留临时目录清理：解压中断（校验失败等提前退出）留下的 `.tmp-*` 超过 1 小时后，下次安装时自动删除。

### 验证

- 预览站实测：`mock-ocr` 市场安装 → 列表出现（来源市场副本）→ 卸载 → 再次安装，均返回 200，`data/market-plugins/mock-ocr/` 结构与 `plugin.json` 正常，无残留临时目录。

## v3.0 · 2026-11-24

主题：插件市场（在线安装与升级，双目录策略）。

### 新增

- **后端市场模块**：新增 `public/lib/plugin_market.php`，提供索引客户端（`BG_PM_IndexClient`）、来源配置（`BG_PM_SourceConfig`）、版本比较（`BG_PM_VersionUtil`）、纯 PHP ZIP 读取器（无 zip 扩展也可用）、包校验与安装器（`BG_PM_Scanner`/`BG_PM_Installer`，支持升级、卸载、回退）。
- **接口**：`public/actions/market.php` + `$ACTIONS` 新增 10 项：`plugin.market.capabilities/list/detail/install/upgrade/uninstall/rollback`、`plugin.source.get/save/test`。
- **双目录策略**：必备插件仍在 `public/plugins/`（市场只读，随系统包更新）；市场插件安装到 `data/market-plugins/`（唯一写根，App 热更只覆盖 `public/`）；同名 id 市场优先，卸载后回落必备基线，纯必备插件不可卸载。
- **前端页面**：新增 `public/js/views/plugin-market.js`（`#/market`），支持全部/可升级/已安装筛选、状态标签、详情弹窗、来源配置与连接测试；顶栏齿轮菜单新增「插件市场」入口与升级数量角标，识别插件设置页头部新增入口按钮。
- **发布流水线**：新增 `.github/workflows/plugin-release.yml`（推送 `plugin-<id>-vX.Y.Z` 标签时校验清单、打包、建 Release、回写 `plugins-index.json`）与索引骨架 `plugins-index.json`。
- **版本判定**：`api.php` 新增 `bg_app_version()`（`3.0.0`），供市场按 `minSystemVersion` 判断插件是否适配本系统。

### 说明

- 接口路径、返回结构、数据库结构与 `plugin.json` 协议均不变；插件市场不写入 `data/plugins.json`。
- 市场索引默认来源为 GitHub 上的 `plugins-index.json`（`plugin` 分支），可在页面「来源设置」改为自建地址（必须 https）。
