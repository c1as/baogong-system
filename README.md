# 报工管理系统

面向机加工车间的轻量化计件报工系统：管理零件与工序单价、订单、报工记录，自动核算金额，并提供统计、导出和数据备份。后端为 PHP + SQLite，前端为原生 HTML / JS / CSS，单文件部署，适合放在群晖 Web Station 等 PHP 环境中内网使用。

> 当前仓库为 **SQLite 版本**（数据存储在 `data/db/baogong.sqlite`）。早期的 JSON 文件存储版本保留在 git 历史中（提交 `3aca7bf`），可随时回退。

技术细节见 [docs/项目文档.md](docs/项目文档.md)，识别插件开发见 [docs/OCR插件接入文档.md](docs/OCR插件接入文档.md)。

## 功能特性

- **零件管理**：每个零件可设置多道工序与单价，支持图号查重、批量 CSV 导入。
- **订单管理**：订单号自动生成（`PO+日期-序号`），按图号 + 工序汇总，显示已报 / 总数量 / 剩余。
- **报工录入**：选零件自动带出工序和单价，金额自动计算；一条报工单可含多个明细；订单可留空，保存时自动建单。
- **拍照识别报工**：在新增报工页拍照或选图，由识别插件自动填充日期、零件、工序、数量，人工核对后保存。识别能力以插件形式接入，内置「百度云 OCR」真实识别插件；设置页提供「API 链接测试」（验证插件接口与密钥）和「互联网连接测试」（验证服务器出网）。
- **报工统计**：按日期范围、订单（多选）、零件筛选，列表同时展示订单数量与实际报工数量。
- **附件**：报工单可上传多张照片，删除报工/附件时自动清理磁盘文件。
- **数据量统计**：展示条数、数据库 / 图片 / 备份占用与年度分布，超过 8MB 提示归档。
- **拍照识别补救**：识别结果面板列出原文，点任意一行即可在表单里自由搜索选择零件、选择工序、调整数量与日期后填入，未自动匹配的文字也能用上。
- **日期范围筛选**：订单记录、报工单记录、报工统计统一使用快捷范围（本月 / 近一周 / 近一个月 / 近三个月 / 近一年 / 全部 / 自定义），导出 CSV 跟随当前范围。
- **导入导出**：CSV 明细导出（带合计，支持月份筛选）、JSON 全量备份与恢复；数据库快照可创建、带备注、一键恢复、下载与删除。
- **访问控制**：`app.env` 设置单一访问密码，登录失败有节流。
- **移动端适配**：手机底栏导航，页面自适应窄屏。

## 快速开始

### 本地运行

需要 PHP 8.x 并启用 `pdo_sqlite` / `sqlite3` 扩展：

```powershell
php -S 127.0.0.1:8080 -t public
```

然后浏览器打开 http://127.0.0.1:8080。首次访问会自动创建 `data/db/baogong.sqlite`；若 `data/` 下有旧的 `db.json`，会自动导入并改名为 `db.json.imported` 留档。

访问密码在 `app.env` 中配置（复制 `app.env.example` 为 `app.env`，修改 `APP_PASSWORD`；留空表示不登录）。

### 部署到群晖

完整步骤（Web Station 站点创建、SQLite 扩展启用、数据目录权限、从旧 JSON 版迁移等）见 [部署说明.md](部署说明.md)。

## 识别插件

拍照识别的「识别」部分不在主程序里实现，而是由 `public/plugins/<id>/` 下的插件提供。主程序负责上传图片、校验与归一化结果、把结果填入报工单；插件只负责把图片变成结构化字段。

内置插件：

- `mock-ocr`：演示插件，不调用任何外部服务，按零件库随机生成示例识别结果，用于验证流程。
- `baidu-ocr`：真实识别插件，调用百度智能云通用文字识别（高精度版），按行匹配零件库的图号 / 名称与工序，并解析数量。
- `qwen35-ocr`：真实识别插件，调用阿里云百炼 Qwen3.5-OCR，擅长手写体与复杂排版。
- `mimo-v26-flash`：真实识别插件，调用小米 MiMo 开放平台 `mimo-v2.6-flash` 视觉模型，支持思考模式、自动重试与零件库注入。
- `ocr-log`：识别日志插件，默认启用；记录每次识别的引擎、耗时、字段、明细、告警与零件匹配候选，按天写入 `data/ocr-logs/`，设置页可配置记录级别、保留天数与是否记录匹配结果。
- `ocr-ensemble`：多引擎融合插件，不直接访问外网；按设置交叉调用多个已启用识别插件，逐字段投票、置信度加权并计算一致性系数，输出综合置信度与分歧告警。设置页可勾选参与引擎、调整一致判定阈值与最低置信度。

拍照识别条右侧可在已启用引擎之间切换，默认优先使用融合引擎；设置页顶部的「识别引擎」卡片可设置默认引擎。

接入其他 OCR（通义、PaddleOCR 或自建服务）时，复制一份插件目录并改写 `handler.php` 即可，主程序无需改动。

### 百度云 OCR 接入步骤

1. 登录 [百度智能云控制台](https://console.bce.baidu.com/ai/#/ai/ocr/overview/index)，开通「文字识别」服务。
2. 在「文字识别 → 应用列表」创建应用，记下 **API Key** 与 **Secret Key**。
3. 打开本系统「识别插件设置」，在「百度云 OCR」卡片填写 API Key / Secret Key，识别类型选「高精度含位置版」（只有含位置版返回文字坐标，能把手写单的分列内容还原成表格行），点击「保存设置」。
4. 点「API 链接测试」：服务器会真实请求一次 token 接口，返回「接口连接正常，密钥有效」即配置成功。
5. 若失败，先点「互联网连接测试」区分是网络问题还是密钥问题。
6. 项目已内置 CA 证书 `public/lib/cacert.pem`，无需修改 `php.ini` 即可通过严格证书校验；若服务器已在 `php.ini` 配置 `curl.cainfo` / `openssl.cafile`，优先使用服务器配置。仅当公司网络使用自签证书时，才需要把该证书追加到 `cacert.pem`，或临时勾选插件里的「跳过 HTTPS 证书校验（调试）」，正式环境请关闭。

token 会缓存在 `data/plugin-cache/baidu-ocr-token.json`（有效期 30 天），失效或更换密钥后会自动重新获取。

手写单的识别策略（不要求按标准格式书写）：

- **文字块合并成行**：按每个文字块的纵坐标聚类，把同一水平线上的「图号 / 工序 / 数量」合成一行再解析，避免分列书写导致错配。
- **一张单一个日期，可对应多个零件**：日期按整张单识别一次，所有明细共用；若行距过小导致多个零件被并成一行，会按图号锚点切段，分别解析各自的工序与数量。
- **日期**：支持 `2026-11-20`、`2026.11.20`、`2026年11月20日`、`20261120`，也支持不带年份的 `11.20` / `11-20` / `11月20日`（按当年补全）；仍识别不到时可按设置填当天。
- **零件**：图号的空格、短横线、点先归一化（`90535 R183` = `90535-R183` = `90535R183`）；支持省略前缀（`523R301` → `TD90523R301`）、缺字 / 多字（`30607R22` → `T306077R22`）、图号尾部粘连数量（`523R30130` → 取 `523R301`）；最后按相似度模糊匹配并尝试零件名称。
- **工序**：先做名称包含匹配，再查同义字典（铣加工↔铣、钻孔↔钻、车外圆↔车、去毛刺↔钳 等）。字典可在「识别插件设置 → 百度云 OCR → 工序同义字典」里按 `铣 = 铁削, 锐加工` 的格式逐行补充，与内置字典合并。
- **数量**：优先取带单位（件 / 个 / 只 / 根 / 套 / 支 / 片）的数字，并排除图号内部的数字。

识别结果面板会列出**识别原文的每一行**，并标注该行解析到的日期、图号、工序、数量。自动填充后仍有缺漏时，点选对应原文行，用下方「日期 / 零件 / 工序 / 数量」按钮手动填入；日期填入表头，零件会新增或复用空行，工序和数量填入最近一个有零件的明细行。

### 目录约定

```text
public/plugins/<id>/
├── plugin.json   清单（id 必须与目录名一致）
├── handler.php   识别处理器
└── check.php     可选：自检脚本，供设置页「API 链接测试」调用
```

### plugin.json

```json
{
  "id": "mock-ocr",
  "name": "模拟识别（演示）",
  "version": "0.1.0",
  "description": "说明文字",
  "author": "作者",
  "capabilities": ["report.ocr"],
  "entry": "handler.php",
  "check": "check.php",
  "settings": [
    { "key": "endpoint", "label": "接口地址", "type": "text", "placeholder": "https://" },
    { "key": "apiKey", "label": "API Key", "type": "password", "hint": "保存后回显为 ********" },
    { "key": "rows", "label": "识别行数", "type": "number", "default": "2" }
  ]
}
```

`settings` 会渲染为设置页里的表单；支持 `text` / `password` / `number` / `select` / `checkbox` / `textarea`（多行文本，可配 `rows`）。配置保存在 `data/plugins.json`。

### handler.php

处理器由 `api.php?action=plugin.invoke` 加载，读取全局上下文后 `return` 统一结果：

```php
$ctx = $GLOBALS['BG_PLUGIN_CTX'];
// $ctx['image']   data:image/... 的图片
// $ctx['catalog'] 零件目录 [{no, name, processes:[工序名]}]
// $ctx['config']  设置页保存的参数
// $ctx['today']   服务器当天日期 YYYY-MM-DD

return array(
    'engine' => 'my-ocr',
    'confidence' => 0.92,
    'fields' => array(
        'date' => '2026-11-20',
        'items' => array(
            array('partNo' => 'P-1001', 'process' => '车', 'qty' => 12),
        ),
    ),
    'warnings' => array('可选提示'),
    'raw' => '识别到的原文',
);
```

也可以改为定义 `function bg_plugin_run($ctx)` 返回同样结构。主程序会用 `partNo` / `partName` 匹配零件、用工序名匹配单价，未匹配到的行会提示人工修正。插件是服务端 PHP，安装前请自行确认来源可信；建议在 `handler.php` 开头判断 `$GLOBALS['BG_PLUGIN_CTX']` 是否存在，避免被浏览器直接访问。

### check.php（可选）

清单里声明 `"check": "check.php"` 后，设置页该插件卡片会出现「API 链接测试」按钮，点击调用 `api.php?action=plugin.check&id=<id>`（即使插件停用也可测试）。自检脚本读取同一份 `$GLOBALS['BG_PLUGIN_CTX']`（`config` 为已保存的参数），返回：

```php
return array(
    'ok' => true,                       // 总体是否通过
    'message' => '接口连接正常',          // 结论，显示在结果顶部
    'details' => array(                 // 逐项明细
        array('label' => '密钥配置', 'ok' => true, 'detail' => '已保存'),
        array('label' => '获取 token', 'ok' => true, 'detail' => '成功 · 320 ms'),
    ),
);
```

设置页顶部的「互联网连接测试」独立于插件，由 `api.php?action=net.check` 在服务器上访问 `https://www.baidu.com/` 与 `https://aip.baidubce.com/oauth/2.0/token`，返回每个地址的 HTTP 状态、耗时与错误信息，用于区分「服务器出网问题」和「插件密钥问题」。

### 页面位置

- 新增报工页顶部「拍照识别报工单」：拍照或选图后自动填表。
- 左侧栏「识别插件设置」（或识别条右侧「识别设置」）：顶部为互联网连接测试；每个插件可启用 / 停用、修改参数、保存设置、测试识别、API 链接测试。

## 数据与备份

- 主数据库：`data/db/baogong.sqlite`（WAL 模式，运行时会产生 `-wal` / `-shm` 文件，属正常现象）。
- 图片目录：`data/images/parts/` 存零件图片，文件名优先取零件名称（重名时追加 `-2`、`-3` 或短哈希）；`data/images/attachments/` 存报工附件，文件名形如 `20261120-001`（上传日期 + 当天序号）；`data/images/drawings/` 存零件图纸（图片或 PDF），文件名形如 `零件名-1.pdf`。
- 自动快照：距上次超过 12 小时自动用 `VACUUM INTO` 生成一份 `.sqlite` 快照，保留最近 20 份，存放在 `data/snapshots/`。
- 手动快照：左下角「数据备份」可随时创建快照并填写备注（如「月末结账」），手动快照保留最近 60 份；列表显示时间、类型、数据量、大小，可直接恢复 / 下载 / 删除。
- 恢复：在快照列表点「恢复」即可回到该时间点，恢复前会自动再存一份「恢复前」快照；也可用「从 JSON 备份恢复」导入文件，或把备份 `.sqlite` 改名为 `baogong.sqlite` 放回 `data/`。
- 迁移：快照只含数据库，图片在 `data/images/{parts,attachments,drawings}`，迁移服务器时请连同整个 `data/` 一起复制。
- 旧结构自动升级：首次运行新版本时，`data/baogong.sqlite` → `data/db/`，`data/backups/` → `data/snapshots/`，图片根目录文件按类型分到 `parts/`、`attachments/`，完成后写入 `data/.storage-v2` 标记，不会重复迁移。

## 常见问题

- **500 `could not find driver`**：PHP 未启用 `pdo_sqlite` 扩展，在 Web Station 的 PHP 配置里勾选即可。
- **百度云 OCR 识别失败**：先点设置页「互联网连接测试」确认服务器能访问 `aip.baidubce.com`；再点「API 链接测试」确认密钥有效。若提示 `invalid_client`，说明 API Key / Secret Key 填写有误或应用未开通文字识别。
- **500 数据目录不可写**：给 `data/` 目录 Web 用户读写权限，并确认 `open_basedir` 未限制该目录。
- **直连 github 推送超时**：本机走代理时，推送需带代理环境变量，例如 `$env:HTTPS_PROXY='http://127.0.0.1:7890'; git push`。

更多排错与迁移说明见 [部署说明.md](部署说明.md)。
